# MIPLIB Combined Collection

Union of all MIPLIB editions, filtered to "easy" instances (solvable within
one hour by a commercial solver) with at most 100k rows and 100k columns.
Models from earlier editions are preserved even if dropped from later ones —
those were typically removed for being too easy, making them ideal for
testing non-commercial solvers.

MIPLIB 2.0 and 3.0 predate the easy/hard/open classification;
all their models are included. MIPLIB 2003 models are also all included
(2 removed only for exceeding the size limit).
