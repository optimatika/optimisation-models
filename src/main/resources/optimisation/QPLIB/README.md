# QPLIB

Subset of QPLIB (A Library of Quadratic Programming Instances) with at
most 10k variables and 10k constraints. 70 larger instances and one
additional instance excluded for file size are listed in the table but
not included; they can be downloaded from qplib.zib.de.

QPLIB collects quadratic programming instances spanning a wide range of
problem structures: linear, convex, and non-convex objectives; continuous,
binary, integer, and mixed variables; and linear through non-convex
quadratic constraints. Each instance is classified by a three-letter
problem type code (see below).

## Problem Types

Each instance has a three-letter code describing objective, variables,
and constraints:

**1st letter - Objective:**

| Code | Meaning |
|:----:|:--------|
| C | Convex quadratic |
| D | Convex diagonal quadratic |
| L | Linear |
| Q | Non-convex quadratic |

**2nd letter - Variables:**

| Code | Meaning |
|:----:|:--------|
| B | Binary |
| C | Continuous |
| G | General integer and continuous |
| I | General integer |
| M | Mixed binary and continuous |

**3rd letter - Constraints:**

| Code | Meaning |
|:----:|:--------|
| B | Bounds only (no general constraints) |
| C | Convex quadratic |
| D | Convex diagonal quadratic |
| L | Linear |
| N | No constraints (unconstrained) |
| Q | Non-convex quadratic |
