# Meszaros

LP test set collected by Csaba Meszaros at MTA SZTAKI (Computer and
Automation Research Institute, Hungarian Academy of Sciences, Budapest).
71 linear programming instances in MPS format, formulated as
minimisation problems.

This is the "misc" subset of Meszaros's broader LP test collection,
which also includes NETLIB, Kennington, infeasible, stochastic LP,
and other problem sets.
